# scrollis-frontend

## Pre-requisites
- Node.js v18.16.0 or higher
- npm v9.5.1 or higher
- Xcode 15.0 or higher (for iOS development)
- Android Studio 2022.3.1 or higher (for Android development)


## Project setup
```
npm install
```

## Running the app
### iOS
```
npm run ios 
```
Note: Make sure you have an iOS simulator running or a physical device connected.
